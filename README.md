# StudyTrack

COMP3074 Mobile Application Development I
Mechel Fernando | Student ID: 101352126 | Team P 46

## Purpose
StudyTrack helps students keep assignments from different courses in one place and see upcoming deadlines.

## UI Prototype
- Assignment list sorted by due date
- All, Pending, and Completed filters
- Add assignment form with required-field validation
- Date picker and Low, Medium, or High priority
- Assignment details and optional notes
- Edit assignments
- Mark assignments completed or pending
- Delete confirmation

## Design
The app has three main screens: Assignment List, Add/Edit Assignment, and Assignment Details. It uses Kotlin, Jetpack Compose, and Material 3.

## Run
Open the project in Android Studio, allow Gradle to sync, and run the app on an emulator or Android device with API 26 or higher.

## Current Limitations
This prototype starts with sample assignments. Changes are held in memory and reset when the app restarts. Permanent local JSON storage is planned for the next development stage.
